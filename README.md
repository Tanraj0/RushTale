## RushTale - The best nodejs/browser game made with AI

RushTale is a game used with [Node.js](https://nodejs.org/en/download) but also can be played on [any browser](https://justavmguy.github.io/RushTale/). The game is a retro game where you run from obstacles and dodge spikes. This was made with Claude and Gemini, so it is a really fun game.
>  [!CAUTION]
>  This game is only able to be played if you get Node.js (doesn't apply to browser edition), otherwise it cannot open!
